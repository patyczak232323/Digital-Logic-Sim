# CPU4 — tiny 4-bit computer in RHDL

CPU4 is deliberately the easiest complete processor in the Rewired examples.
It is meant to be readable before looking at Rewired-8.

## Build

Open `00_CPU4.rhdl` in RHDL Studio and choose **BUILD & OPEN**.

There are no custom-chip dependencies. CPU4 uses only ordinary Rewired
primitives plus logic generated by RHDL.

## Architecture

- 4-bit accumulator `A`
- 4-bit program counter: 16 program addresses
- logical 16 x 4-bit data RAM
- 8-bit fixed instruction word
- instruction format: `OOOO DDDD`
  - `OOOO`: 4-bit opcode
  - `DDDD`: immediate/address operand
- `Z` flag is true when the accumulator equals zero
- 4-bit `OUT_PORT` register
- one instruction per rising clock edge
- Harvard-style program ROM and data RAM
- `RESET` clears registers and data RAM

The stock simulator ROM is 256 x 16. CPU4 uses only addresses 0..15 and only
the **low byte** of each ROM word. Therefore an 8-bit instruction `0x13`
is entered in the ROM editor as `0x0013`.

## ISA

| Opcode | Mnemonic | Operation |
| --- | --- | --- |
| 0 | NOP | no operation |
| 1 | LDI n | A <- n |
| 2 | LDA a | A <- RAM[a] |
| 3 | STA a | RAM[a] <- A |
| 4 | ADD a | A <- A + RAM[a] (low 4 bits) |
| 5 | SUB a | A <- A - RAM[a] (low 4 bits) |
| 6 | AND a | A <- A AND RAM[a] |
| 7 | OR a | A <- A OR RAM[a] |
| 8 | XOR a | A <- A XOR RAM[a] |
| 9 | JMP a | PC <- a |
| A | JZ a | if Z, PC <- a |
| B | JNZ a | if !Z, PC <- a |
| C | NOT | A <- NOT A |
| D | INC | A <- A + 1 |
| E | OUT | OUT_PORT <- A |
| F | HLT | halt until RESET |

Arithmetic naturally wraps modulo 16.

## First program

This stores 3 in RAM[0], loads 2, adds RAM[0], sends 5 to OUT_PORT and halts.

| Address | ROM word | Assembly |
| ---: | ---: | --- |
| 0 | `0013` | `LDI 3` |
| 1 | `0030` | `STA 0` |
| 2 | `0012` | `LDI 2` |
| 3 | `0040` | `ADD 0` |
| 4 | `00E0` | `OUT` |
| 5 | `00F0` | `HLT` |

Expected final state:

- `ACC = 5`
- `OUT_PORT = 5`
- `RAM[0] = 3`
- `PC = 5`
- `HALTED = 1`

## Tiny loop example

A continuously increasing 4-bit counter:

| Address | ROM word | Assembly |
| ---: | ---: | --- |
| 0 | `0010` | `LDI 0` |
| 1 | `00E0` | `OUT` |
| 2 | `00D0` | `INC` |
| 3 | `0091` | `JMP 1` |

OUT_PORT cycles through 0..15 and wraps back to 0.
